# Arcade_Sample
Arcade is a Python library that provides a great next step for those who have learned programming with Scratch. This repository contains sample programs for learning Python Arcade.

| Number | Program | Contents |
| --- | --- | --- |
| 1 | arcade_sample1.py | Define and initialize MyGame class. |
| 2 | arcede_sample2.py | Drawing update |
| 3 | arcede_sample3.py | Animation |
| 4 | arcede_sample4.py | A ball that bounces off the wall |
| 5 | arcede_sample5.py | Increase the number of balls |
| 6 | arcede_sample6.py | Display a sprite. |
| 7 | arcede_sample7.py | Chasing the mouse pointer |
| 8 | arcede_sample8.py | Press the button to start the game. |
| 9 | arcede_sample9.py | Restrict the rotation direction to left and right only |
| 10 | arcede_sample10.py | The sprite jumps when the space bar is pressed　|
| 11 | arcede_sample11.py | A sound plays when hitting an enemy sprite.　|
| 12 | arcede_sample12.py | Change background　|
| 13 | arcede_sample13.py | Release balls in concentric circles　|
| 14 | arcede_sample14.py | The sprite avoids the enemy sprite by jumping　|
